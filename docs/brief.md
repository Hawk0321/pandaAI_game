# 寻找你的交易人格（PandaAI 苏客松参赛项目）

> 一句话目标：做一款几分钟就能玩完的游戏，从玩家的选择和操作里读出 **有依据、可修正** 的交易画像，再给出 **因人而异、能马上动手** 的下一步（数据 / 工具 / 课程 / 研究任务）。

赛题：PandaAI 苏客松｜寻找你的交易人格：用游戏认识用户，让推荐因人而异

---

## 1. 核心闭环

```
游戏互动  →  行为证据  →  画像（含不确定项）  →  推荐 + 理由  →  可体验的下一步
   ↑                                                              │
   └──────────── 信息不足 / 线索冲突时补充互动，修正画像 ←──────────┘
```

评委看的是这条链能不能完整跑通，以及"了解了用户什么，因此推荐了什么"。标签数量、技术堆叠、模拟收益排名都不加分。

### 初步方向（待确认）

- **主线**：基于 Panda Data 的历史行情复盘游戏。玩家只看到当时可见的信息做判断，之后揭晓结果，判断过程即画像证据。
- **辅线（可选）**：玩家上传自己的交易记录，作为次要证据，用来提高或降低已有画像判断的置信度。

## 2. 我们要做到的事（按评分维度）

基础评分 100 分，决定一、二、三等奖（1 万 / 6 千 / 4 千元）。

| 维度 | 分值 | 我们的目标 |
|---|---|---|
| 趣味性与体验设计 | 25 | 新手几分钟内能看懂并玩完核心流程；每个玩法动作都能产生有意义的测评线索，而不是换皮问卷 |
| 用户画像的合理性 | 25 | 只选与场景相关的少数维度做深；每个判断都写清"观察到什么行为 → 得出什么判断 → 还不确定什么"；**能力和偏好分开**；收益不能是能力的唯一标准；能处理信息不足和线索冲突 |
| 个性化推荐价值 | 25 | 不同行为路径产生合理且不同的推荐；每条推荐带匹配理由；至少一个类别做深，并连到一个能当场体验的下一步 |
| Panda Data 应用价值 | 15 | 数据要实质参与情境、画像或推荐；少量数据做透即可；写清关键字段和时间口径；**严格区分玩家当时可见的信息与之后揭晓的结果** |
| 完成度与创新性 | 10 | "互动 → 画像 → 推荐 → 下一步"完整可运行；在玩法、测评方法或推荐体验上至少有一处可演示的创新 |

### 可选：PandaAI 应用潜力奖（单独评选，满分 15，不影响等级奖）

- 用户与场景契合度（5）：理解 PandaAI 用户的实际任务和关键差异
- 画像与推荐的可用性（5）：结果能调整引导、匹配具体资源、推动用户开始任务
- 接入与持续应用潜力（5）：易嵌入产品流程，画像和依据可结构化输出，便于维护扩展

为此我们输出一份结构化结果（JSON），至少包含：

```json
{
  "dimensions": [
    {
      "name": "验证习惯",
      "judgement": "倾向先下结论再找证据",
      "evidence": ["第2关未查看成交量直接买入", "第4关拒绝查看回测结果"],
      "confidence": "medium",
      "uncertain": "尚不清楚是不会看还是不想看"
    }
  ],
  "recommendations": [
    {
      "type": "task",
      "resource": "示例：用历史数据验证一个均线假设",
      "is_sample": true,
      "reason": "与'验证习惯'判断对应",
      "next_step": "进入 3 步引导任务"
    }
  ]
}
```

（以上字段和内容仅为格式示意。）

## 3. 范围约定

- **画像维度**：从知识与能力、交易偏好、研究习惯、兴趣、学习需求中挑与我们场景相关的几项做深，不追求全覆盖。人物卡（如"交易物种"）只是画像的趣味表达。
- **方法**：规则、统计或 AI 都可以，不强制使用大模型。
- **推荐对象**：数据、工具、课程、策略探索方向里至少一类做深。资源可以是真实的，也可以是明确标注的示例，但匹配逻辑必须是真的在跑。
- **不需要**接通 PandaAI 生产环境。

## 4. 交付物

- [ ] **可体验的作品**：游戏原型或应用，完整呈现互动、画像、推荐、下一步（提交形式优先选 **支持手机访问的 H5**）
- [ ] **项目说明**：目标用户和使用场景、玩法、画像维度与行为依据、推荐逻辑、Panda Data 使用方式、已知局限
- [ ] **差异化演示**：至少两组不同行为路径，展示画像、推荐、后续体验如何变化（可放进演示视频）
- [ ] **演示视频**：3–5 分钟
- [ ] **代码与运行说明**：依赖、配置、启动方式；需要登录时提供测试账号
- [ ] 可选：真实试玩记录（与模拟示例分开标注）、PandaAI 接入构想、结构化画像与推荐结果示例

## 5. 提交要求与硬性约束

提交：截止前把 H5 链接或完整工程代码发到 **code@pandaai.online**，邮件写明作品名称、团队名称、联系人。截止时间以赛事最终通知为准。H5 在评审期间必须能正常访问。

必须遵守：

1. **披露来源**：列出第三方组件、开源项目、AI 工具和赛前已有成果，标明比赛期间完成的核心工作。
2. **标注未完成项**：未实现的功能、示例数据、模拟用户、模拟推荐都要明确标注。
3. **数据与隐私**：不在仓库、演示材料中公开数据访问密钥；不含未经授权的个人信息；使用真实用户信息要告知用途；公开分享人物卡时不自动展示私密原始行为记录。
4. **信息隔离**：用历史行情出题时，玩家只能看到"当时可见"的数据，结果揭晓后才展示后续走势。

## 6. 现场演示准备

- 准备至少两条差异明显的行为路径，跑给评委看画像和推荐怎么变。
- 评委可能临场改一个关键选择，结果要能按我们自己的逻辑合理调整（不要求每次都换标签）。
- 遇到证据不足时，敢于展示"保留判断 / 补充互动"，这本身是加分项。
