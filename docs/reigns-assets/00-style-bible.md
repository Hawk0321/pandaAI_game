# 滑牌游戏美术与音乐：统一风格锁定（所有素材文档必须遵守）

> 这是规划文档，不是实现。三份素材清单（事件卡人物、属性图标与结局、音乐音效）都以本文为准。
> 对象读者：美术同学，以及要用 AI 生图、AI 作曲的人（所以提示词写得尽量能直接复制使用）。
> 所有素材是原创虚构内容，不得模仿任何现有游戏、品牌或真人。

## 1. 一句话风格

像素大头人（chibi pixel bust portrait）：只画头和肩，头占画面约 70%，大眼睛、简化五官，
用手绘感像素风，色板有限，描边统一，背景是单色或极简场景色块。
参考“滑牌决策游戏里的人物立绘”的使用方式（人物为主体、一眼认出身份、夸张表情），
但造型、配色、角色全部原创，不复刻任何现有游戏的角色或画风。

## 2. 硬性规格（所有人物与图标共用）

| 项 | 规定 |
|---|---|
| 像素网格 | 人物原图 64×64 像素，导出时放大 5 倍取整，最终 320×320，邻近采样（nearest neighbor），不要抗锯齿 |
| 属性图标 | 16×16 像素原图，导出放大到 32×32 和 48×48 两档 |
| 结局插图 | 128×96 像素原图，导出放大 3 倍为 384×288 |
| 色板 | 全局 32 色，见第 3 节；单张素材最多用其中 16 色 |
| 描边 | 1 像素，深色（#0a0d15 墨蓝），不用纯黑；内部不加描边 |
| 光源 | 左上方向，阴影用同色系暗一级，不做渐变和半透明 |
| 背景 | 人物卡背景为单色色块 + 最多 2 个简单装饰色块；透明背景版本另导出一份 PNG 供界面叠加 |
| 格式 | PNG（无损）；最终接入时转 WebP，单张不超过 30KB；不要提交超过 10MB 的文件（AGENTS.md） |
| 命名 | 小写英文 + 连字符 + 编号，如 `npc-fund-sales-director-neutral.png` |

## 4. 人物的统一画法

- 视角：正面，微微 3/4 侧，肩部带一点衣领或标志性配饰来表明身份。
- 头：圆润大头，眼睛占脸宽约 1/4，眼白 + 一个深色瞳孔，眉毛 2 像素粗，嘴巴用 2–4 个像素表达。
- 表情：每个人物最少 3 种（neutral 平静、happy 得意/高兴、worried 担忧/惊慌），关键人物额外 angry、sly（狡黠）。
- 身份识别靠“一个标志性道具 + 一种主色”，不靠文字。例：销售总监 = 红领带，合规专员 = 眼镜 + 文件夹。
- 避免真实：不画真实名人、不画可识别的真实 logo。
