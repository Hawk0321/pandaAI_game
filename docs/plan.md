# 一天开发计划（总纲）

> 4 个开发分开做，靠 [沟通协议](protocol.md) 对接。每个人把自己那份任务文档和协议一起交给 AI 就能开工。
> 本轮范围：**游戏 → 行为证据 → 画像**。推荐和演示先不做，后面再排（协议里已留好位置）。

## 做什么

手机打开的 H5 小游戏，5 分钟玩完：

1. 看一段隐去名称和日期的真实历史 K 线（Panda Data）。
2. 用有限的研究点翻线索卡（成交量、均线、大盘、资金面、回测）。
3. 下决定：方向、仓位、信心、止损。
4. 后续走势分三步揭晓，每步可以持有、加仓、减仓或平仓。
5. 揭晓真实标的和 3 个 AI 对手的表现。
6. 玩完 4 关出画像（能力和偏好分开、带证据和置信度）；看不准的地方再来一关补充关卡，画像随之更新。

## 完成标准（四块合起来要做到的）

- [ ] 手机打开链接，新手不看说明 5 分钟内能玩完一局。
- [ ] 至少 8 关真实 Panda Data 关卡，覆盖 6 种行情；`docs/panda-data.md` 写清接口、字段和时间口径。
- [ ] 玩家做决定之前，前端拿不到任何后续数据。
- [ ] 每个动作都有行为事件，事件格式符合协议。
- [ ] 画像有 6 个维度，能力和偏好分开，每个判断有证据、置信度和不确定项。
- [ ] 证据不足时会进补充关卡，补充关卡后画像会说明哪里变了。
- [ ] 3 种不同玩法得出明显不同的画像，改一个关键选择画像会合理变化。
- [ ] 示例数据、未完成功能都有标注；没有提交密钥。
