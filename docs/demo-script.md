# 3–5 分钟演示脚本：两条差异玩家路径

> 给现场演示和录屏用。核心主张一句话：**同一套关卡，不同的玩法，得到不同的画像、不同的人物卡、不同的推荐——而且每条结论都能点开看证据。**
> 两条路径用 `data/samples/profile/` 的两组模拟玩家（`sample_player_cautious.json`、`sample_player_impulsive.json`），画像和推荐都是规则计算，示例数据已标 `is_sample`。

## 准备（演示前）

- `cd frontend && npm run dev`，手机或 375px 窗口打开首页；另开一个标签页备好推荐自测页 `/src/recommend/demo.html?player=cautious` 和 `?player=impulsive`。
- 两份示例画像对应的数值见下表，讲的时候直接念。
- 时间不够时跳过"现场玩一关"，直接从第 2 节开始。

## 0:00–0:40 开场：赛题和玩法

- "交易人格不是问卷测出来的，是做出来的。"
- 玩法 20 秒讲完：看 60 根 K 线 → 用 3 个研究点翻线索（翻不完）→ 选方向、仓位、信心、止损 → 提交后行情分三步揭晓，每步可以持有/加仓/减仓/平仓 → 4 关之后生成画像。
- 行情来自 Panda Data 的历史真实数据，玩家看到的只有决定时刻之前的信息，之后的走势提交后才加载（代码里 `decision` 之前不会调用揭晓）。

## 0:40–1:30 现场玩一关（展示动画和证据采集）

- 翻两张线索卡：卡片翻面、研究点递减、剩下翻不起的卡自动置灰并写明"研究点不足"。
- 选做多 / 中仓 / 信心 3 / 止损 5%，提交：决定时刻竖线画出，之后的 K 线一根一根出现，记分板跟着跳。
- 顺口说一句："每一次翻牌、每一次下单、浮亏时加仓还是减仓，都是一条行为事件，画像就从这些事件算出来。"

## 1:30–3:00 路径一 vs 路径二：画像和人物卡

打开两份示例画像（或先后切换两个标签页），并排讲。

| | 谨慎研究型（`cautious`） | 冲动重仓型（`impulsive`） |
|---|---|---|
| 怎么玩的 | 研究点用满、关键线索全翻到；仓位适中、会设止损 | 一张线索不翻就重仓；平均仓位 100%、信心 5/5；浮亏不收手 |
| 人物卡 | 🦉 夜猫研究员（另外也有点像 🐢 稳健老龟） | 🐂 冲锋蛮牛（另外也有点像 🦔 死扛刺猬） |
| 卡片上的"为什么是你" | 研究点使用 100%，关键线索命中 100% | 平均仓位 100%，平均信心 5.0/5，命中率 50% |
| 能力：证据使用 | 0.86 高置信 · 会先找关键线索，决定和证据一致 | 0.18 高置信 · 倾向先下结论，较少依据线索 |
| 能力：判断校准 | 0.81 高 · 信心和对错比较匹配 | 0.35 中 · 信心和实际对错不匹配 |
| 能力：风险控制 | 0.82 高 · 会用止损和仓位管住风险 | 0.28 高 · 风险敞口偏大，浮亏时不太收手 |
| 偏好：趋势 vs 反转 | 0.33 中 · 偏逆势反转 | 1.00 高 · 偏趋势跟随 |
| 偏好：研究深度 | 0.98 高 · 先把研究点用足再决定 | 0.26 高 · 很少翻线索、决定快 |
| 偏好：风险偏好 | 0.43 高 · 仓位适中 | 1.00 高 · 常常重仓、愿意加仓 |

讲法：

1. 先指人物卡：两张完全不同的动物，"为什么是你"那一行就是本局数据，不是贴标签。
2. 再指六个维度：能力和偏好分开，分数旁边有置信度；点开"查看证据"，每条证据都写着第几关、哪一步、支持还是反对，还能展开当时的原始动作。
3. 特意点一个"还不确定什么"：谨慎型的趋势 vs 反转看不准——我们宁可说不知道，也不硬下结论。评委问"会不会乱贴标签"时就用这一条回答。

## 3:00–4:15 推荐：下一步去哪儿 vs 先在游戏里练一练

画像页下面有两块推荐，分工不同，都写明依据哪项判断、引用哪条证据：

| | 谨慎研究型 | 冲动重仓型 |
|---|---|---|
| **下一步去哪儿**（引流 PandaAI / QuantSkills，最多 4 张，必有一张 PandaAI 产品卡） | ① 策略：把找线索的本事用到因子上 → `skill-pandaai-factor-online` ② 产品：量化因子中心 ③ 活动：第四届因子大赛 ④ 工具：`skill-backtest-overfit` 防过拟合 | ① 工具：把止损写成规则 → `skill-b11-auto-stop-loss-take-profit` ② 策略：把"顺势"写成均线策略 → `skill-ma-crossover-signal` ③ 产品：Qube 一句话生成可回测策略 ④ 学习：量变学院量化思维入门 |
| **先在游戏里练一练**（4 张技能卡，优先 2 张，用本局已揭晓行情当场练） | 趋势追踪卡、反转确认卡优先（风格还不明显，先探索） | 止损护盾卡、趋势追踪卡优先（风控短板最急） |

讲法：

1. 冲动型第一张是止损工具，谨慎型第一张是因子大赛——推荐顺序由画像里最突出的短板或特点决定，不是固定清单。
2. 点开冲动型的"止损护盾卡"：同一笔入场加一条保护线，当场看收益和回撤的差别，玩家不用离开游戏就能验证画像说的问题。
3. 点一张引流卡的"去试试"：跳到 PandaAI 真实页面（Qube / 因子中心 / 模拟赛），这就是从游戏到产品的闭环。

## 4:15–4:45 收尾：交付物和边界

- "导出提交版 JSON"：六个维度（判断 + 证据 + 置信度 + 不确定项）和四张推荐（理由 + 下一步），对应赛题第 2 节要求。
- 边界三句话：规则计算、不是投资建议；模拟行情不能证明真实交易能力；示例数据都标了 `is_sample`。
- 可选加分：再来一关补充观察 → 第二轮画像列出"哪些判断变了"。

## 备用问答

- **为什么不用大模型？** 规则可追溯，每条结论能指到具体动作；大模型只做可选润色（`method: rules+llm`）。
- **数据从哪来？** Panda Data 历史行情，见 `docs/panda-data.md`；玩家看不到决定之后的数据。
- **9 张人物卡怎么判别？** 16 个会话级行为特征直接判别，见 `docs/features.md`、`docs/personas.md`。
- **推荐规则在哪？** `docs/recommend.md`（引流卡片）和 `docs/skill-cards.md`（游戏内技能卡）。
