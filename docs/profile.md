# 画像规则说明（证据与画像模块）

> 写给评委和队友：我们怎样从玩家的操作里读出画像，每一步用了什么规则、阈值是多少、为什么这样定。
> 代码在 `frontend/src/profile/`，阈值集中在 `evidence.ts` 的 `T`，本文和代码保持一致。目前全部是规则计算（`method: "rules"`），没有用大模型。

## 1. 总体思路：先找证据，再下判断

```
玩家的每个动作（翻线索、下决定、持有/加仓/减仓）
   → 证据层：一条条"观察到的行为"，每条都指向具体的事件编号
   → 判断层：把同一维度的证据汇总，给出判断、分数、置信度、冲突和"还不确定什么"
   → 人物卡：维度组合映射成一个趣味名字（只是趣味表达，不是结论）
   → 看不准时：挑一关补充关卡，补完后说明哪些判断变了
```

三条原则：

1. **能力和偏好分开。** 能力有好坏之分（证据使用、判断校准、风险控制）；偏好没有对错（趋势/反转、研究/直觉、激进/保守），只说明倾向。
2. **收益不进入任何能力打分。** 赚钱可能只是运气，亏钱也可能是好决定。我们看的是"决定的过程"：看没看关键线索、信心和对错是否匹配、仓位和止损是否合理。
3. **证据不足就说不知道。** 没有可用的行为就不下结论（`score: null`，置信度低），并写清楚还缺什么。

## 2. 六个维度的规则

每条证据有一个 0–1 的分值：能力维度越高越好，偏好维度表示倾向位置。某个行为和维度相关但看不出方向时，分值为空，只作为"不确定"的说明列出（页面上显示为 `?`）。

### 能力 1：证据使用

| 观察 | 分值 | 依据 |
|---|---|---|
| 关键线索覆盖：翻开了本关几张关键线索（`key_clue_ids`，由关卡作者按事后结果标注） | 0.15 + 0.75 × 翻开比例；本关没有关键线索时按 1 处理 | 研究点有限（每关 3 点），会不会把点花在最有判断价值的线索上，是区分新手和老手的核心 |
| 决定与线索一致：翻开的线索看涨/看跌合计后，决定方向是否一致 | 翻 ≥2 张：一致 0.8 / 相反 0.2；只翻 1 张：一致 0.6 / 相反 0.3；一致的分值再乘 `0.4 + 0.6 × 关键线索覆盖率` | 只翻一张就下单，"一致"说明不了多少，所以降权。只翻到顺着自己方向的线索时，"一致"是廉价的一致，所以再按覆盖率折算——漏掉全部关键线索时，0.8 会被折到 0.32，不再能冲掉"没看关键线索" |
| 一张线索没翻就下单 | 0.15 | 完全没有依据 |
| 线索多空抵消后选择观望 | 0.7 | 证据不支持任何方向时不下注，是合理的用法 |
| 确认偏误：翻了 ≥2 张且全部支持自己的方向，反方向线索没翻，同时漏了关键线索 | 0.25 | 只找支持自己想法的证据 |

### 能力 2：判断校准（不看赚多少）

信心 1–5 分别视为"自认为判断正确的概率" 50%、60%、70%、80%、90%。

| 观察 | 分值 | 依据 |
|---|---|---|
| 单关：信心与方向对错（Brier 分） | 1 − (信心概率 − 对错)² / 0.81 | 信心 5 且对了 ≈ 1；信心 5 却错了 = 0；信心 1 错了 ≈ 0.69（本来就不确定，不算失准） |
| 跨关汇总（≥2 次可检验判断）：平均信心 vs 实际命中率 | 1 − 2 × 信心高出的部分 − 1 × 信心低出的部分 | **这是主要依据**，权重等于可检验的关数。一次对错可能是运气，多次才看得出信心是否靠谱。高估比低估扣得多，因为过度自信更危险 |

- 平均信心比命中率高 15 个百分点以上记为"信心偏高"，低 25 个百分点以上记为"信心偏低"。
- 观望的关、或之后横盘（涨跌不到 2%）的关，无法检验对错，只列为不确定。

### 能力 3：风险控制

| 观察 | 分值 | 依据 |
|---|---|---|
| 入场时设了止损（触发时注明把亏损控制在多少） | 0.85 | 事先规定最大亏损 |
| 半仓或满仓却没设止损 | 0.2 | 风险敞口大且没有保护 |
| 轻仓没设止损 | 0.55 | 风险本身不大，不算错 |
| 高波动（决定前 20 天日收益标准差 > 2%）仍满仓 | 0.2 | 仓位应随波动调整 |
| 高波动时只用半仓或轻仓 | 0.75 | 同上 |
| 浮亏超过 1% 时加仓 | 0.1 | 典型的"摊平"冲动 |
| 浮亏超过 1% 时减仓或平仓 | 0.85 | 及时止损 |
| 浮亏超过 8% 才减仓或平仓 | 0.6 | 有止损意识，但执行偏晚 |
| 浮亏时继续持有 | 0.45 | 中性略偏负 |

持仓按事件顺序更新：`stop_triggered` 已自动平仓时，后续空仓等待不作为“浮亏继续持有”评分；玩家加仓重新入场后，再继续评价后续持仓动作。

### 偏好 1：趋势 vs 反转

看决定前 20 天的涨跌：超过 ±3% 才算有趋势。上涨时做多、下跌时做空记为顺势（1），反过来记为逆势（0）。没有趋势或观望的关只列为不确定。

### 偏好 2：研究深度

分值 = 0.7 × 研究点使用比例 + 0.3 × 平均每张线索的阅读时间（`min(每张停留 / 15 秒, 1)`；没翻线索时为 0）。研究点用足、每张线索看得进去偏"研究型"，很少翻线索、几下就决定偏"直觉型"。这里不用总思考时间：总时间实际测的是"打开页面的快慢"，手机慢一点就会被算成研究型。

### 偏好 3：风险偏好

分值 = 仓位（观望 0、轻仓 0.2、半仓 0.5、满仓 1）+ 每次加仓 0.15，最多 1。

## 3. 从证据到判断

- **分数**：同一维度所有有分值证据的加权平均。
- **判断**：分数 ≥ 0.65 / ≤ 0.35 / 中间，分别对应三档文字（如"会先找关键线索，决定和证据一致"/"倾向先下结论，较少依据线索"）。没有任何有分值的证据时写"证据不足，暂不下结论"，分数为空。
- **一致性**：只看"有明确方向"的证据（分值离 0.5 至少 0.2），算和多数方向同侧的占比（按权重）。
- **冲突**：两个方向都有明确证据，且少数一方占比 ≥ 1/3，标 `conflict: true`，并写明"有时……有时……，还不清楚……"。
- **置信度**：
  - 高：证据来自 ≥3 关，一致性 ≥ 80%，且没有冲突；
  - 中：证据来自 ≥2 关，一致性 ≥ 60%；
  - 低：其余情况（包括只有 1 关、证据不足、冲突严重）。
- **还不确定什么（`uncertain`）**：置信度不是高时一定填写，按"证据不足 / 有冲突 / 只有 1 关 / 方向基本一致但关数少"给出对应说明。
- **每条证据的 +/−/?**：和最终判断同方向记 `+`，反方向记 `-`，看不出方向记 `?`。所以页面上能直接看到"哪些行为支持这个判断、哪些反对"。

## 4. 人物卡（趣味标签）

人物卡只是画像的趣味表达，标 `is_fun_label: true`。按顺序匹配，第一条命中即用：

| 条件 | 人物卡 |
|---|---|
| 风险偏好 ≤ 0.2（大多观望或极轻仓） | 🦥 树懒观察员 |
| 风险偏好高 + 研究深度低 | 🐂 冲锋蛮牛 |
| 研究深度高 + 证据使用好 + 风险控制不差 | 🦉 夜猫研究员 |
| 风险偏好高 + 研究深度高 | 🦈 深海猎鲨 |
| 风险偏好低 + 研究深度不低 | 🐢 稳健老龟 |
| 趋势偏好 ≤ 0.35 | 🦀 逆行螃蟹 |
| 趋势偏好 ≥ 0.65 | 🐬 冲浪海豚 |
| 都不满足 | 🦊 灵活狐狸 |

（"高/低"指 ≥ 0.65 / ≤ 0.35。）总评里会写出人物卡的依据，比如"仓位重、研究少、决定快"。

## 5. 补充关卡和第二轮画像

- `needs_more`：所有置信度低或有冲突的维度，能力维度排在前面，理由就是该维度的"还不确定什么"。
- `pickNextLevel()`：只为**能力维度**补关（偏好维度没有对错，不值得多玩一关去确认）。在置信度低或有冲突的能力维度中，按置信度从低到高、同档时冲突优先排序，依次从关卡池里找 `probes` 包含该维度、且没玩过的关卡；都找不到或能力都已看准时返回 `null`。第 2 轮之后不再补关。
- 第 2 轮 `analyze()` 用全部关卡（主线 + 补充关）重新计算，再和第 1 轮比较：判断、置信度、冲突状态任一变化就写入 `changes`（"之前 → 之后"）；都没变时在总评里说明"补充关卡没有改变任何判断"。

## 6. 三条演示路径（模拟玩家）

`data/samples/profile/` 里有 3 组模拟玩家（全部是模拟数据，关卡也是公式生成的模拟行情），测试会确认它们的画像明显不同：

| 模拟玩家 | 玩法 | 画像要点 | 补充关卡 |
|---|---|---|---|
| 谨慎研究型 | 先翻关键线索，半仓以下并设止损，浮亏减仓 | 🦉 夜猫研究员；三项能力都高；趋势偏好有冲突（顺势逆势都做过，可能是在跟着线索走） | 不需要 |
| 冲动重仓型 | 几秒决定，最多翻 1 张，满仓不止损，信心总是 5，浮亏加仓 | 🐂 冲锋蛮牛；三项能力都低。**有两关赚了钱，校准仍判为"信心偏高"**（信心 90%、命中 50%）——收益不决定能力 | 不需要 |
| 只看不做型 | 认真翻线索，但四关都观望 | 🦥 树懒观察员；判断校准、风险控制"证据不足，暂不下结论" | 补 1 关 → 校准、风控、趋势从"证据不足"变成低置信度的初步判断 |

现场改一个关键选择（测试里也覆盖了）：

- 冲动重仓型在第 2 关改成"设 5% 止损、浮亏立刻平仓"：风险控制分数上升，其他维度不变。
- 谨慎研究型在第 2 关改成"只看均线就满仓做多、浮亏加仓"：证据使用和风险控制下降，判断校准里出现"信心很高，但方向判断错了"的反向证据。

## 7. 已知局限

- 阈值是根据游戏设计和常识定的，没有用真实玩家数据校准。
- 一局只有 4–5 关，样本少，所以大多数判断最高只到"中"置信度；这是有意保守。
- "关键线索"由关卡作者按事后结果标注，带有出题人的判断。
- 跨关的汇总证据（判断校准）挂在最后一关上，页面只能高亮那一关的决定事件。
- 模拟玩家和模拟关卡只用于测试和演示，不代表真实用户。
