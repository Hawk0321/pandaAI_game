# 画像后的推荐技能卡

## 玩家流程

主线画像或补关后的第二轮画像 → 四张卡（前两张优先推荐）→ 点击体验 → 选择已完成关卡 → 调整参数、比较结果或复盘动作 → 完成练习 → 导出推荐与练习 JSON。

这项功能在画像后出现。卡片仅拿到本局已完成关卡和本局事件，不发起新的关卡请求；未完成的补关不会进入选择列表。固定示例画像不显示针对本局的推荐，避免把固定样例结论冒充玩家特征。真实和模拟关卡分别沿用原画像的 `is_sample` 标记。

## 推荐规则

推荐排序由实际维度、分数、置信度和冲突决定，不以人物卡名字或收益排名决定。

| 卡片 | 优先条件 | 玩家可以做什么 |
|---|---|---|
| 止损护盾 | 风控分数低于 0.55 优先；不确定时推荐探索 | 选择多空、仓位、止损/止盈线，与相同初始仓位无保护线持有对照 |
| 交易复盘 | 校准分数低于 0.55、低置信度、无分数或冲突；其次证据使用较弱 | 查看关键线索覆盖、信心与方向结果、持仓亏损时加仓，并选择下次改动 |
| 趋势追踪 | 风格分数至少 0.65 且中/高置信度、无冲突 | 调整快均线 5/10、慢均线 20/30、仓位，与相同仓位 t=0 做多持有对照 |
| 反转确认 | 风格分数至多 0.35 且中/高置信度、无冲突 | 调整确认窗口 1/3/5 根与仓位，比较等待确认和直接入场 |

排序分值在 `model.ts` 集中维护，取前两张优先显示，其余仍可探索。低置信度时使用“还看不准/探索建议”，不把不确定的分数断言成能力缺陷；风险偏好不作为能力扣分依据。每张卡最多引用两条可核对证据，事件必须同时匹配当前会话、关卡和序号；找不到时说明证据不足。

## 练习算法与成交口径

- 趋势：每根开盘前，用截至前一收盘的快慢 SMA 比较确定多/空/观望目标；在当前开盘调仓，换方向先平仓。不会用当前收盘决定当前开盘订单。
- 反转：用此前 20 根最高价做线性拟合并外推压力线，要求斜率为负、收盘低于压力线至少 2%。随后在确认窗口内收复触发日收盘且当根收阳，下一根开盘做多。与触发后下一根开盘直接做多对比；此前可见数据用于维护待确认形态，但不虚构 t<0 的练习成交。只允许一次入场并持有到练习结束。无确认就保持空仓，不能用后续结果倒填入场。
- 护盾：在 t=0 收盘建立玩家选择的练习方向与仓位，此后逐根检查止盈止损。若开盘已越过保护线，以开盘退出；否则同根触及两线时保守按止损优先。退出后不再入场。游戏交易原始的“触发价成交”口径不变，此卡是单独的对照实验。
- 复盘：只引用本关真实的 `decision` / `clue_open` / `hold_step` / `stop_triggered` 事件。自动止损清空持仓后，重新入场不误记为浮亏加仓；本关观望或后续横盘时不判方向对错。用户选定下一步后显示可验证的练习反馈，不重算本局画像。
- 权益从 1 开始，仓位是初始资金占比。收益为期末盯市收益；回撤为逐日收盘权益的峰谷回撤，未建模盘中回撤、费用、滑点、A 股真实做空约束或期货保证金。不同入场时点和多空规则在对照说明中明示，原玩家收益仅作上下文。

所有参数均可在已揭晓行情上调整，这是学习用回放，不是样本外验证；单段比较不会成为新的画像证据，也不承诺某策略更优。

## QuantSkills 来源与改动

本项目独立编写浏览器游戏规则，仅参考以下技能的用途与通用算法思路。没有复制其 Python 源码、依赖、模板或输出文本，也没有在浏览器调用完整 Skill 服务。每张卡的“来源与游戏版说明”明确区分两者，链接固定上游版本，避免把简化练习说成完整接入。

| 上游技能与固定版本 | 游戏版本的区别 |
|---|---|
| [skill-ma-crossover-signal](https://github.com/quantskills/skill-ma-crossover-signal/tree/5cdde5cbc8d010d04862d7392c1a27e173109147) | 原版查询单标的 SMA/EMA 和交叉快照；本卡使用已完成关卡的 SMA 逐日回放，游戏多空规则也适用于已有黄金/白银关卡 |
| [skill-b11-auto-stop-loss-take-profit](https://github.com/quantskills/skill-b11-auto-stop-loss-take-profit/tree/bb7ba0deee3d2a8be2ab1d027792fa981dc6e8ed) | 原版有次日开盘、两日强平和单票仓位约束；本卡采用 15 日逐根保护线，无两日强平和 10% 上限 |
| [skill-trendline-breakdown-reversal](https://github.com/quantskills/skill-trendline-breakdown-reversal/tree/0e33deadd53b2ad77127e3f05267d889dd152b50) | 原版为 A 股全市场因子；本卡为单段已完成行情的形态等待练习，明确分开触发与后续确认 |
| [skill-trade-review](https://github.com/quantskills/skill-trade-review/tree/883fbf25668409d3cee19733f422ba3e0e1068b9) | 原版处理规范化真实交易、归因与可选 LLM；本卡只复盘本局游戏事件 |

上游技能标注 GPL-3.0/GPL-3.0-only（交易复盘标注在其嵌套 Skill 目录）。当前实现没有将这些上游代码作为依赖或再分发；后续如果直接调用或引入上游代码，需另行处理运行环境、数据适配与来源/许可证要求。

## 导出与隐私

原 Profile JSON 导出维持不变。新增独立 `skill-practice/v1` JSON，包括当前会话/画像轮次、`is_sample`、推荐列表、已完成的练习参数、结果/成交和来源版本。引用本局证据序号，未附原始事件日志，不包含凭证，不上传服务器。

练习在本页内存保留。刷新、重新开始或进入补关后会清空练习记录，页面明确提示先导出；重复完成相同卡片/关卡会更新该项结果。练习不会写入游戏日志、改变原收益或提高画像分数。暂未实现真实账户交易、完整 QuantSkills 执行环境和跨设备练习存档。

## 验证与来源披露

54 项前端测试（其中新增 10 项技能卡规则测试）、TypeScript / Vite 构建通过。Chrome CDP 三条真实主线路径验证不同优先推荐，全部四张卡可操作、参数进入导出、结果无 NaN、原画像及事件不变、练习不额外取关卡数据、375px/桌面宽度正常。原有补关、第二轮、刷新与协议夹具仍通过。桌面模拟不能替代新版真实手机网络验收。

游戏数据来自现有 Panda Data 历史题库；界面与规则代码由 OpenAI Codex 协助独立完成。继续使用现有 React、TypeScript、Vite、Vitest，未新增第三方运行依赖。
